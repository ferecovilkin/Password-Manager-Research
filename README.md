# 🔐 Password Manager Research

This project compares popular password managers from a security perspective.

## 🔎 Password Managers

The following password managers will be researched:

- Bitwarden
- KeePass 2
- 1Password
- KeePassXC
- Proton Pass
- Dashlane

## 🎯 What I Will Research

For each password manager, I will look at:

- How passwords are stored
- Encryption methods
- Key Derivation Function (KDF)
- Multi-Factor Authentication (MFA)
- Open-source or closed-source
- Local or cloud storage
- Security audits
- Known vulnerabilities
- Privacy
